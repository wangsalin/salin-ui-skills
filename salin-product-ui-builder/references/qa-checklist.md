# UI 验收清单

## 产品与流程

- [ ] 页面用户、主任务和成功标准明确。
- [ ] 主操作突出，次级和危险操作权重正确。
- [ ] 进入、完成、失败、取消、返回和恢复路径可用。
- [ ] 文案具体一致，术语与产品其他页面一致。

## 视觉与系统

- [ ] 只使用一个主视觉方向；若本次允许重塑视觉，记忆点有意义且不破坏既有系统。
- [ ] 颜色、字体、间距、圆角、阴影和图标来自一致体系。
- [ ] 没有无意义卡片网格、默认紫蓝渐变、泛滥玻璃或空洞文案。
- [ ] 层级在缩小、眯眼或灰度观察时仍清楚。

## 完整状态

- [ ] loading、empty、error、disabled、success 和权限状态完整。
- [ ] 长文本、无数据、大数字、慢网和重复操作不会破坏布局或流程。
- [ ] 表单错误可定位、可恢复并保留输入。

## 响应式与无障碍

- [ ] 手机、平板、桌面没有横向溢出，内容按任务重新排列。
- [ ] 键盘可完成关键流程，焦点清晰且顺序合理。
- [ ] 触摸目标、对比度、语义标签和减少动画符合要求。
- [ ] 浮层、抽屉、软键盘和安全区行为正常。

## 工程验证

- [ ] 复用现有技术栈、tokens 和组件，没有无必要依赖。
- [ ] 运行可用的格式化、lint、类型、测试和构建。
- [ ] 在真实浏览器中走过至少一条关键业务流程。
- [ ] 汇报未运行检查、未验证设备和残余风险，不虚构通过结果。
