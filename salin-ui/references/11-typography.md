# 11 · 排版系统（Typography）

字阶管"多大"，本文件管"怎么排"。中文 UI 排版质量 80% 来自这里，不是字号。

## 字阶

### 移动端
| 用途 | 字号 / 字重 | 行高 |
|---|---|---|
| 辅助信息、时间戳、状态胶囊 | 12px / 400 | 1.4 |
| 正文、列表、表单 | 14px / 400 | 1.6 |
| 小标题、按钮文字 | 16px / 500 | 1.5 |
| 卡片标题 | 20px / 600 | 1.4 |
| 页面标题 | 24px / 700 | 1.3 |
| Hero 大数字（只在主 KPI 卡） | 32~40px / 700 | 1.2 |

### 桌面端
| 用途 | 字号 / 字重 |
|---|---|
| 表头、辅助信息、时间戳 | 12px / 500（表头）· 400（辅助） |
| 正文、表格、表单 | 14px / 400 |
| 按钮、导航 | 14px / 500 |
| 卡片标题、区块标题 | 16px / 600 |
| 页面标题 | 20~24px / 700 |
| Hero 大数字（只在主 KPI 卡） | 32~40px / 700 |

- 中文字体栈：`PingFang SC, HarmonyOS Sans SC, "Microsoft YaHei", "Noto Sans SC", sans-serif`（系统字体优先，不为"设计感"引入装饰字体）。
- 数字：`tabular-nums` + `SF Mono, Roboto Mono, monospace`（数字跳动不抖）。
- 中文 900 字重：正文/UI 文字禁用；仅展示型大标题经风格明确指定可用（如明黄市集）。

## 中文排版规则

1. **行长**：中文正文每行 28–40 字；英文 45–75 字符。超出则收窄容器或分栏，不许满屏长行。
2. **行高**：正文 1.6–1.8（长文本取大）；标题 1.2–1.4；12px 小字 1.4。
3. **对齐**：中文一律左对齐；居中只给短标题、空状态、数字。**禁用两端对齐（justify）**——中文会产生不均匀空隙。
4. **标点**：全角标点；不用半角逗号句号；省略号/破折号占两格。
5. **字距**：标题 -0.01em ~ -0.02em；正文 0；12px 小字可 +0.01em 保可读。
6. **段间距**：段与段 ≥ 1 个行高；列表项之间 ≥ 8px。
7. **换行**：标点不居行首（CSS `line-break: strict`）；英文单词不拆行。
8. **层级**：一屏标题层级 ≤ 3 级；超过说明信息架构有问题，先砍内容。
9. **中英混排**：UI 内紧凑不加空格；长文案中数字/英文前后可加四分之一空格（不强制）。

## 数字规则
- 价格/积分/百分比/倒计时一律 tabular-nums 等宽，右对齐。
- 大数字加千分位；小数点后位数全站统一。
