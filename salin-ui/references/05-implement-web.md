# 05 · 桌面端实现（implement-web）

桌面端网页：官网 / 营销页、SaaS 工作台与后台、普通网页。信息密度高但不乱，视觉克制可信。

## 技术栈
默认输出**单文件 HTML**（内联 CSS/JS，双击即看）。用户指定技术栈（React / Vue / Next.js 等）则按指定输出，不擅自混用。

## 核心流程
1. 确认目标：页面用户、主任务、主操作、业务约束、可观察的验收标准。
2. 检查现状：已有项目先读 README、依赖、路由、组件、tokens、Git 状态。
3. 定页面类型：工作台首页 / 三栏创作工作区 / 数据列表页 / 表单·向导页 / 设置页。
4. 取 tokens：默认「暖纸青墨」；高密度页可用「石墨暖灰」；有品牌 VI 的项目品牌优先。
5. 选模式：创作类页面优先三栏工作区；信息类页面优先 KPI 卡 + 数据表。
6. 实现真实界面：主流程 + loading / empty / error / 权限 / 长内容 / 超宽屏；不虚构业务不存在的状态。
## 动效编排（本步的子阶段②，不是独立步骤）
结构、五态、基础交互态（hover/active/focus/transition）完成后，再做动效编排：
1. 查 `data/motions.csv`（检索：`scripts/motion-search.py`）找模式，落具体参数（时长/缓动/位移）。
2. 动效术语查 `data/terms.csv`（53 条），标出处，不编造。
3. 铁律：一屏最多 2 种动效；核心流程只用 1 种；尊重 `prefers-reduced-motion`。
4. 基础交互态不算"动效编排"，不许为凑数把 hover 重做一遍。
7. 真实验收：在浏览器走关键流程（含 1280 / 1440 / 1920 三档宽度）。

## 设计原则
- 桌面端用 8pt 网格；内容区最大宽度 1200~1440px，超宽屏不拉伸。
- 三栏工作区 = 左栏步骤导航（窄）+ 中间画布（最大最亮）+ 右栏参数面板（可折叠）；移动端降级为步骤条 + 单栏。
- SaaS/工作台/表单页不拿营销页式大 Hero 挤压操作空间；官网首屏必须直接说明主体、价值和下一步。
- 数据表：表头弱化（12px 灰字），行高 ≥ 48px；禁用斑马纹，只用 hover 高亮；状态用胶囊，不用整行色块。
- 可点击元素最小 32px；所有图标按钮必须有悬停态。
- 表单：必填项标星号；长表单分组；提交按钮注明消耗（如"生成 · 预计 5 点"）。
- 正文灰不浅于 #6B7280；数字一律 tabular-nums。
- 组件一律圆角（铁律）。
- 禁用：大面积渐变、玻璃拟态、超过 2 层阴影、紫蓝科技风；中文 900 字重仅限展示型大标题且须风格明确指定，正文/UI 文字禁用。

## 完成前检查
- 首屏能否说明当前页面、关键状态和下一步；SaaS 页主操作是否不被 Hero 挤压。
- 1280 / 1440 / 1920 三档宽度下无错位、无意外横向滚动。
- 所有可点击元素有悬停态/焦点态；键盘可走完核心流程。
- 空 / 错 / 加载 / 权限状态齐全。
