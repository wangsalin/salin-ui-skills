# 10 · 设计 Tokens（数值层）

颜色/间距/圆角/阴影/触控的数值总表。风格定调（02）管"选哪套"，这里管"数值是多少"。实现（04/05）必须引用这里的数值，不许凭感觉。

## 间距 / 圆角 / 阴影
- 间距：App 用 8 / 16 / 24 / 32 / 48 五档；Web 用 8pt 网格（8/16/24/32/48/64）。不许出现 10 / 13 / 20 等随意值。
- 圆角：App 卡片 12~16px；Web 卡片 12px、按钮 8px 或 pill、输入框 8px；小标签 6~8px。组件一律圆角（铁律）。
- 阴影：最多 1 层淡阴影（例 `0 1px 2px rgba(0,0,0,0.04)`）；Web 弹窗可用 1 层稍强 + 遮罩 rgba(0,0,0,0.32)。禁用多层投影和彩色阴影。
- Web 布局：内容区 1200~1440px 居中；栅格 12 列，gutter 24px。

## 触控
- App 可点击目标 ≥ 44×44px；Web ≥ 32px（WCAG 2.2 AA 桌面端 ≥ 24px）；相邻目标间距 ≥ 8px。
- App 内容区底部为固定 CTA 预留 ≥ 88px padding（含安全区）。
