# 02 · 风格（style）

解决"每次做 UI 都从零想风格"：6 套精调风格可检索，三旋钮定调，选定后落盘为项目级 `MASTER.md`，后续所有实现按同一份设计记忆执行。

风格库：`data/styles.csv`（石墨青柠/工业深蓝/霓虹暗夜/荧光柠檬/明黄市集/深色画廊）。

## 流程
1. 一句话描述产品（行业/用户/调性），查 `data/styles.csv` 按 Keywords 检索，取 Top 3。
2. 给用户看 Top 3（每套一句话卖点 + 主色），让用户二选一或三选一。**不替用户定风格。**
3. 定旋钮：variance（1 保守–10 出挑）、motion（1 静谧–10 动感）、density（1 疏朗–10 紧凑）。默认 5/5/5。
4. 落盘 `MASTER.md`：项目名、选定风格、旋钮值、主色/字体/圆角摘录。一份 MASTER.md 只对应一个项目。
5. 实现阶段必须完整读取 MASTER.md 后再动手；跨页面有冲突以 MASTER.md 为准。

## 默认推荐方向：苹果风（用户定稿主方向）
> 简约高级感、系统级产品气质。不是视觉特效模板。

**适合**：AI 工具、创作工具、效率工具、移动端 App、轻量 SaaS、消费级产品页。
**谨慎**：重运营 CRM、超高密度表格后台、强促销电商（可借鉴层级与控件，不牺牲效率）。

**核心原则**：
- 内容优先：首屏先给任务、状态、主操作，不用装饰性大标题占满空间。
- 系统秩序：稳定字号层级（见 11-typography.md）、明确控件分组、可预测导航。
- 真实留白：留白服务分组和呼吸感，不把工具页撑成展示页。
- 轻材料感：半透明/背景模糊/细边框只用于导航、浮层、工具栏等材料层，且必须有可读性兜底（边框+实色背景+对比度）。
- 克制动效：短时长、自然缓动，支持 reduced motion。
- 低噪色彩：足够对比度、清晰 focus、稳定布局，可长期使用。

**落地要点**：
- 系统字体栈（见 11-typography.md），不为"苹果感"引入装饰字体。
- 语义 token：background / foreground / card / muted / border / ring / accent。
- 主容器圆角 12–20px；阴影要轻，优先边框和层级。
- 移动端：触控 ≥ 44px；390px/430px 必查；底部主操作不被键盘遮挡。

**禁区**：
- 不把苹果风等同于毛玻璃、巨大圆角、银灰背景。
- 不复制 Apple 官网布局到后台/表格/CRM/表单流。
- 不用满屏模糊渐变、光斑、漂浮设备壳掩盖信息结构。
- 不为"高级"降低按钮可发现性、输入边界、错误提示。

**验收**：三秒看懂页面任务和主操作；字号/留白/圆角来自统一规则；动效关闭后页面仍完整可用。

## 铁律
- 风格二选一必须用户拍板，不许代选；旋钮可以给推荐值。
- 风格的"不适用"字段是红线：命中不适用场景必须换，不许硬套。
- 零命中时回退默认风格（暖纸青墨），并明确告诉用户是回退。
- 有既定品牌 VI 的项目（如 Munch 墨黑+炭火橙），品牌优先，不走检索。
