# 空间系统（salin-ui-layout 共用，v2 新增）

对标 GitHub：agent-design-taste（4px 间距系统/栅格对照）、saglitzdesign-mcp（间距编码层级）、stackkeel（全宽 vs 受限宽/不叠第二层 padding）。

## 基准
- 4pt 基准间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。App 优先 4pt，Web 优先 8pt 网格。
- 圆角（硬规则，见 salin-ui-components）：App 卡片/弹窗 16px、按钮 12px；Web 卡片 12px、按钮 8px。禁用直角。

## 断点
- App：360（小屏）/ 390（基准）/ 430（大屏）。
- Web：768（平板）/ 1024（小桌面）/ 1440（大桌面封顶，内容区不拉伸）。

## 容器与边距
- App 屏边距：16px（≤390）/ 20px（大屏）；卡片间距 12px；楼层间距 20–24px。
- Web 内容宽：1200–1440px 居中；屏边距 24px（≤1024）/ 32px（>1024）；section 纵间距 72–112px。

## 铁律
1. **间距编码层级**：组内间距 < 组间距 < 区块间距（如 8 < 16 < 32）。proximity 即分组——间距乱 = 层级乱。
2. **不叠第二层 padding**：容器定一次边距，子元素不再各自加边距。
3. **全宽 vs 受限宽二分法**：背景可全宽（沉浸感），内容必须受限宽（可读性），二者不混用。
