## 字阶（移动端优先）
| 用途 | 字号 / 字重 | 行高 |
|---|---|---|
| 辅助信息、时间戳、状态胶囊 | 12px / 400 | 1.4 |
| 正文、列表、表单 | 14px / 400 | 1.6 |
| 小标题、按钮文字 | 16px / 500 | 1.5 |
| 卡片标题 | 20px / 600 | 1.4 |
| 页面标题 | 24px / 700 | 1.3 |
| Hero 大数字（只在主 KPI 卡用） | 32~40px / 700 | 1.2 |

- 中文字体栈：`PingFang SC, HarmonyOS Sans SC, "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 数字字体：`tabular-nums` + `SF Mono, Roboto Mono, monospace`（数字跳动不抖）
- 中文慎用 900 字重（非 Retina 屏会糊，反而廉价）

## 间距 / 圆角 / 阴影
- 间距：8 / 16 / 24 / 32 / 48（不许出现 10 / 13 / 20 等随意值）
- 圆角：卡片 12~16px；胶囊/按钮 pill 全圆角；小标签 8px
- 阴影：最多 1 层，极淡（例：`0 1px 2px rgba(0,0,0,0.04)`）；禁用多层投影和彩色阴影
- 触控：最小 44×44px；内容区底部为固定 CTA 预留 ≥ 88px padding（含安全区）
