# 布局模式库（移动端 App）

每个模式：做法 → 适用页面 → 反模式（不要做成什么样）。

## 1. Hero KPI 主卡
- 做法：首页顶部只放一张大卡 = 大数字（32~40px，tabular-nums）+ 一句话说明 + 环形/条形进度 + 一个主按钮。整屏有且只有一个视觉主角。
- 适用：首页、工作台首页。
- 反模式：顶部堆 3~4 张小统计卡，或者 Hero 只放装饰图没有数字和动作。

## 2. 一个主 CTA + 底部抽屉
- 做法：复杂功能入口收进 1 个「开始创作」大按钮，点开后底部抽屉/弹出层里再选具体类型；高级参数默认折叠（渐进式披露）。
- 适用：首页、多类型创作工具。
- 反模式：8 个平权入口平铺，首页像工具箱。

## 3. 底部固定主按钮（拇指热区）
- 做法：移动端关键页底部固定一条安全区内的全宽大按钮（≥44px 高），内容区留出底部 padding。核心动作永远一 tap 可达。
- 适用：首页、向导页、结果页（底部变成保存/发布）。
- 反模式：主按钮藏在右上角或需要滚动很久才看到。

## 4. 状态胶囊
- 做法：12px 文字 + 6px 色点的小胶囊：进行中（琥珀 #D97706）、已完成（绿 #2F9E63）、失败（红 #DC2626）。操作列用图标按钮，不用文字按钮堆砌。
- 适用：任务中心、历史列表、积分明细。
- 反模式：整行大色块背景表示状态；红色用于普通提示。

## 5. KPI 小卡（三件套）
- 做法：灰色小标题 → 大数字 → 绿↑/红↓百分比胶囊 → 右上角迷你折线。每张卡只回答一个业务问题（"发了多少""涨了还是跌了"）。数字必须配对比和趋势，不许裸数字。
- 适用：数据页、首页第二屏。
- 反模式：只有数字没有环比；一张卡塞 3 个指标。

## 6. 空状态建议卡
- 做法：空界面不留白，放 3~4 张建议卡（标题 + 一句话 + 箭头），点一下直接填入输入框或跳对应流程。
- 适用：生成器空状态、知识库空状态、搜索无结果。
- 反模式：大面积空白 + 一句"暂无数据"。

## 7. 左图右文信息行
- 做法：图是信息载体不是装饰——缩略图（1:1 或 4:3）+ 右侧标题/两行描述/状态胶囊。图、文、状态在同一行完成一次信息扫描。
- 适用：产品库、作品库、任务列表。
- 反模式：纯线条图标列表；图和文字信息脱节。

## 8. 深色结果页（仪式感）
- 做法：工作区保持浅色，只有"生成结果/海报预览"用方案 C 深色沉浸式展示。深色 = 出片、成就感的仪式感，不是默认皮肤。
- 适用：结果页、海报预览、成就页。
- 反模式：全站深色；深色页用纯黑 + 高饱和霓虹。

## 9. 步骤向导（大编号）
- 做法：步骤条用 "01 / 04" 大编号 + 短标题；每步一屏只做一件事；底部固定上一步/下一步；确认页汇总全部选择 + 点数抵扣。
- 适用：多步表单、创作向导。
- 反模式：一屏塞完所有表单项；步骤藏在顶部小圆点里看不清进度。
