# Salin UI Motion · 顺滑组件交互

## Purpose
为常用 UI 组件配上"点下去那一下"的反馈质感：8 种经短视频验证的交互模式，每种给效果规格、动效参数和可直接用的 AI 提示词。蒸馏自 @叨叨AI《8个让App和小程序变顺滑的组件交互》（2026-09-30）；视频只给定性描述，数值参数按 iOS HIG / Material Motion 补齐为推荐值。

## Workflow
1. 明确场景：哪个组件、什么触发、用户要感知到什么。
2. 从下面 8 种模式里选 1 种（最多 2 种叠加，贪多则乱）。
3. 套"全局动效默认值"的时长与缓动，特殊需求再微调。
4. 输出：AI 提示词（丢给 VibeCoding 用）或交互说明文档；实现时按参数逐项落实。
5. 用 Operating Rules 自查一遍，不合规的改掉而不是解释。

## 全局动效默认值（推荐值）
- 时长三档：微反馈 150–200ms（按钮、图标翻转）；组件过渡 200–300ms（弹窗、Tab、FAB）；页面/流程切换 300–400ms（分步弹窗高度过渡）。
- 缓动：进入用 ease-out（cubic-bezier(0.2, 0, 0, 1)）；退出用 ease-in；状态来回切换用 ease-in-out；iOS 端可用 spring（damping ≈ 0.8）。
- 位移：底部弹窗从 translateY(100%) → 0；横滑内容 = ±100% 宽度；小位移反馈 4–8px。
- 数字滚动一律 tabular-nums 等宽，避免跳动。
- 必须尊重 `prefers-reduced-motion`：降级为 opacity 淡入淡出或直接切换，不许强行动画。

## 交互模式（8 种）

### 1. focus-timer · 顶部计时小条
顶部固定细条展示倒计时/进度。数字每秒更新（tabular-nums），进度填充用 300ms linear 过渡；结束时条色一闪或轻微脉冲一次。
适用：番茄钟、专注、订单倒计时类顶部状态。
提示词模板："做一个顶部计时小条：固定在顶部，左侧倒计时数字（等宽字体、每秒更新），下方细进度条随时间填充，过渡 300ms linear。"

### 2. step-sheet · 分步底部弹窗
底部弹窗承载多步骤流程。切换步骤时内容横向滑动（translateX ±100%，250ms ease-out）；弹窗高度随内容自动平滑过渡（300ms ease-in-out，勿写死高度）；顶部放"STEP n OF m"步骤指示。
适用：预订流程、多步表单、向导。
提示词模板："做一个分步底部弹窗：切换步骤时内容横向滑动，弹窗高度随内容平滑过渡，顶部显示 STEP n OF m；单步内容超高时内部滚动、弹窗不顶出屏幕。"

### 3. dark-mode · 深色模式切换
设置页主题开关。切换时全屏颜色 300ms ease-in-out 过渡，杜绝闪白；sun/moon 图标旋转淡入切换；图片类内容可加一层半透明遮罩过渡。
适用：设置页、个人中心主题切换。
提示词模板："做深色模式切换：开关切换时全屏颜色 300ms ease-in-out 过渡、无闪白，图标旋转淡入切换。"

### 4. tab-bar · 底部导航选中展开
底部 Tab 栏。选中项 pill 背景块滑动到选中位置（250ms ease-out / spring），文字标签随之展开（宽度动画），其余项只保留图标；图标与文字颜色同步切换。
适用：App 底部主导航（3–5 个 tab）。
提示词模板："做底部导航栏：选中项展开显示文字标签，背景 pill 块滑动到选中位置（250ms ease-out），其余项只保留图标。"

### 5. scroll-fab · 悬浮按钮随滚动收起
长列表页的 FAB（新建/添加）。列表下滚时 FAB 收起为纯圆形图标（宽度收缩 200ms ease-in-out）；上滚或回顶时重新展开；收起状态下图标仍可点击。
适用：笔记、待办、消息列表的新建按钮。
提示词模板："做悬浮按钮随滚动收起：列表下滚时 FAB 收成圆形图标（200ms），上滚时展开恢复，收起后仍可点击。"

### 6. copy-button · 复制按钮反馈
点击复制后即时反馈。图标原地翻转成对勾（rotateY 90° 翻转，200ms）+ Toast"已复制"；约 2s 后图标翻回原样。复制失败则 Toast 报"复制失败，请重试"。
适用：订单号、兑换码、邀请码一键复制。
提示词模板："做复制按钮反馈：点一下复制，图标原地翻成对勾（200ms 翻转）+ Toast 已复制，2 秒后恢复；失败时 Toast 报错。"

### 7. form-error · 表单校验反馈
输入校验失败时：输入框红色边框（200ms 过渡）+ 错误文案从上方 4px 淡入；可加一次轻微抖动（幅度 ≤4px，克制使用）；用户修正后错误态 200ms 淡出。错误文案说人话（"手机号少了 1 位"），不说"输入非法"。
适用：登录、注册、报名、下单表单。
提示词模板："做表单校验反馈：校验失败时输入框红边框（200ms）+ 错误文案淡入，文案说人话；修正后错误态淡出。"

### 8. dropdown-select · 下拉选择框
选项选择器。展开时列表自动滚动、以当前选中项为中心对齐；选中后 200ms 收起并更新框内文字；选中项打勾标识。选项超过一屏时列表内部滚动，框体不撑出屏幕。
适用：城市、档位、分类选择器。
提示词模板："做下拉选择框：展开时列表以当前选中项为中心对齐，选中后收回并更新框内文字，选中项打勾。"

## Output Contract
- 按任务交付：AI 提示词（可直接粘贴给 VibeCoding / AI 编程工具）、交互说明文档，或实现要点清单。
- 必须包含：所用模式名（英文代号）、每个动效的具体数值（时长/缓动/位移），不许写"顺滑一点"这类空话。
- 视觉 token（颜色/字号/圆角）不归本 skill 管：移动端查 `salin-app-ui`，网页端查 `salin-web-ui`。

## Operating Rules
1. 一屏最多 2 种动效模式，核心流程只用 1 种；动效是配角，不许抢戏。
2. 所有时长、缓动、位移必须写具体数值；视频没给的按"全局动效默认值"取，不得编造"视频里说的参数"。
3. 尊重 `prefers-reduced-motion`，每个交付都给出降级方案。
4. 可点击元素最小 44px；FAB 收起后仍可点；弹窗不许顶出屏幕、内容超高时内部滚动。
5. 错误/失败反馈必须给：复制失败、校验失败、加载失败都要有明确状态，不许静默。
6. 需要更深的动效理论时查 `ui-ux-pro-max`；要出可交互 HTML 原型时配合 `baoyu-design`。
