# 视觉方向

视觉方向要服务项目类型，不要先套流行风格。

## 方向选择

| 场景 | 推荐视觉语言 | 关键特征 |
|---|---|---|
| AI 产品工作台 | 冷静、清晰、微科技 | 中性底色、清楚输入/输出、轻量动效 |
| 企业 SaaS | 克制、专业、密集 | 表格友好、低饱和、清晰边界 |
| 本地生活商家工具 | 亲近、实用、手机优先 | 大触控、短文案、强主按钮 |
| 工厂 B2B | 工业、可信、证据导向 | 真实图片、参数表、质检/案例证据 |
| 品牌官网 | 主题鲜明、记忆点明确 | 一个 signature element、真实素材 |
| 内容/创作者工具 | 编辑器感、轻表达 | 画布、侧栏、快捷操作、预览 |
| 苹果风格产品界面 | 系统感、内容优先、细腻克制 | 大量真实留白、清晰标题层级、轻材料感、柔和阴影、自然动效 |

## 苹果风格

当用户明确要求“苹果风格、Apple-like、iOS、macOS、Human Interface、高级系统感”时，读 [apple-style.md](apple-style.md)。这里只把苹果风格作为视觉方向入口；具体适用场景、Web/Tailwind/shadcn、iOS、macOS、官网和禁区由独立文件约束。

## 调色原则

- 一个主中性色系、一个强调色、少量状态色。
- 避免一页全是同一色相的深浅变化。
- 避免默认紫蓝渐变、玻璃拟态和无意义光斑。
- B2B 和工具页优先选择耐看的灰、白、黑、低饱和蓝/绿/橙，不用糖果色。
- 苹果风格优先使用中性灰阶、系统蓝/绿/橙等单一强调色和少量透明层；不要把整个页面做成银灰单色堆叠。

## 字体和层级

- 工具页用清晰 sans-serif，少用 serif。
- 营销页可以有 display 字体，但正文必须易读。
- 大标题只给真正的首屏或页面主命题；面板、卡片、表单内标题要紧凑。
- 中文 UI 文案短而具体，按钮使用动词，如“保存设置”“生成脚本”“创建客户”。
- 苹果风格界面可使用更大的页面标题和更清晰的分组标题，但面板、表格、输入区仍要保持紧凑和可操作。

## 记忆点

每个页面最多一个记忆点：

- 独特首屏结构。
- 真实产品/业务画面。
- 强识别的导航或数据结构。
- 轻量动效。
- 品牌化色彩或字体。

记忆点不能妨碍主任务。
