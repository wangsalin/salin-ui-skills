# UI 验收清单

完成前按真实页面检查，不只看代码。

## 3 秒扫描

- 页面/产品是什么。
- 用户下一步该做什么。
- 主按钮是否明显。
- 关键信息是否先出现。

## 结构

- 主操作、次操作、辅助信息层级明确。
- 表单标签、帮助文本、错误文本清晰。
- 表格、筛选、分页、批量操作路径完整。
- 空状态能引导下一步。

## 视觉

- 字号、行高、间距有一致节奏。
- 圆角、边框、阴影不过度。
- 色彩不是单色堆叠，也不是默认紫蓝渐变。
- 卡片没有套卡片。
- 图标风格统一。

## 反 AI 模板

- 不使用默认紫蓝渐变、无意义光斑、装饰 blob、满屏毛玻璃。
- 不使用渐变文字作为主要卖点。
- 不把所有模块做成等宽图标卡片网格。
- 不在每个 section 都加 01/02/03 编号或小号全大写 eyebrow。
- 不在卡片、输入框、主要容器上滥用 32px 以上大圆角。
- 不用“下一代、赋能、无缝、释放潜能、重新定义”等泛泛营销文案替代真实说明。

## 响应式

- 检查 320px、390px、430px、768px、1440px。
- 文案不溢出按钮、标签、导航、表格单元格。
- 移动端触控目标至少 44px。
- 底部按钮、弹窗、抽屉不被浏览器工具栏遮挡。

## 可访问性

- 交互元素有键盘焦点。
- input 有 label 或 accessible name。
- 错误状态不只靠颜色。
- 对比度足够。
- reduced motion 可接受。

## 工程验证

- 跑可用的 lint/typecheck/test/build。
- 浏览器控制台无明显错误。
- 关键流程可点击、可输入、可提交或可模拟。
- 说明未验证内容和原因。
