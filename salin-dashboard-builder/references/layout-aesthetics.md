# 4 种高级审美后台排版

蒸馏自 @叨叨AI《4种高级审美后台排版设计》（2026-09-22）。核心判断（视频原话）："同样是做 Dashboard，为什么有的高级、有的像 AI 模板？差别往往不在组件多复杂，而在配色、层级和版面判断。"——"一整页只做一个判断，定下来再往里填内容。"

## 选型原则

- 一页只做一个排版判断（只留一块深色 / 只用一个强调色 / 层级全交给明度 / 玻璃+方格），不要四种混用。
- 先定判断，再往里填内容；判断定之前不讨论组件细节。

## 1. 方格纸加玻璃卡（Grid & Glass）

**视频基线**：页面底色用 44px 方格纸铺满、四周不留外框；卡片做成半透明白玻璃浮在上面，底下格线能透过来（玻璃拟态）；顶部指标按数值排成递增的阶梯色块，填充从实心换到点阵、斜纹再到渐变；强调色为橙色；卡片大圆角、大量留白。

- 视频原话："它的高级感，靠的是把枯燥的数据表格也玩成了视觉设计。"
- 玻璃卡片需要 backdrop-filter；低性能设备要有实色回退。
- 方格纸是底色纹理，对比要压到不干扰文字阅读。

**AI 描述词**："页面底色用44像素方格纸铺满不留外框，卡片做成半透明白玻璃浮在上面，顶部指标按数值排成递增的阶梯色块"（视频原话）

## 2. 分组侧边栏（Grouped Rail）

**视频基线**：深色格线底上的白色侧边栏卡片；侧边栏按组划分（GROUP 01/02/03），组名用 10px 大写灰字（中文可用 12px 加字距），组和组之间留一大段空白；栏底固定放头像和用量条；主区第一行不放标题，放一句超大的细体文字（如"早上好"），右边并排三个一样大的数字；占比不画饼图，摊成一条横贯整行、四段按比例分宽的比例条。

- 分组来自业务心智，不按视觉均匀硬拆；组间空白 ≥ 32px。
- 超大细体首行是排印判断，字号建议 ≥ 40px、字重 300–400。
- 比例条每段用明度/色相区分并配图例，不只靠颜色。

**AI 描述词**："侧边栏按组划分，组间留大段空白，组名用10像素大写灰字，栏底固定放头像和用量条，主区首行用超大的细体文字，配三个并排大数字，占比用一条横贯的分段比例条"（视频原话）

## 3. 一块深色配一个强调色（One Dark · One Accent）

**视频基线**：整页浅色（米白），全页只有侧边栏那一条是深色（墨黑重底）；全页只用一个强调色（橙色 Accent）；只标三处：当前项、主按钮、图表命中值——命中的柱子用强调色，其他全部退成灰阶；侧栏底部放一张强调色卡片收口（如"新增待办"）。

- 视频点睛："全页只用一个强调色"——克制用色即高级感来源。
- 强调色出现超过三类位置就破功；新增强调需求时先问能不能复用现有三处。
- 深色只给侧栏一处；内容区不再出现第二块深色面。

**AI 描述词**："整页用浅色只给侧边栏一块深色重底，全页只用一个强调色，只标当前项、主按钮和图表命中值，侧栏底部放一张强调色卡片收口"（视频原话）

## 4. 暗底明度分层（Tone Layers）

**视频基线**：整页压到近黑；卡片用比背景亮一档的灰，一条描边都不画，层级全靠明度拉开；主读数给到极大，数字占满、单位缩到角上（小号字）；日期排成一片圆点阵列，有内容的日期顶彩色徽章，空格用斜纹填掉。

- 视频点睛："层级全靠明度拉开""一条描边都不画"。
- 相邻层级明度差 ≥ 8% 才分得开；在真实屏幕上验证，不要只看设计稿。
- 彩色徽章只用于"有内容"的日期标记，全页彩色总数控制在 3 种以内。

**AI 描述词**："做一个深色后台，卡片用比背景亮一档的灰分层不描边，主读数用超大数字配小号单位，日期区用圆点阵列加彩色徽章"（视频原话）
