# 图表选型指南

先根据用户要完成的判断选择图表，再考虑视觉风格。以下是默认起点；数据规模、屏幕尺寸和用户专业度会改变选择。

## 从业务问题选择

| 用户要回答的问题 | 首选表达 | 可选交互 | 常见误用 |
|---|---|---|---|
| 完成多少、离目标多远 | 活动圆环、进度条、子弹图 | 查看组成、切换周期 | 用多个圆环比较精确差异 |
| 哪些日期活跃、是否形成习惯 | 日历热力格 | 日期详情、范围切换 | 用颜色代替精确值且无图例 |
| 当前值属于哪个阈值区间 | 仪表盘、子弹图 | 阈值说明 | 单个精确数值占用过大空间 |
| 比较少量类别或周期 | 柱状图、点图 | 选择、排序、周期切换 | 类别过多仍强塞移动端横轴 |
| 不同状态如何沿时间分布 | 专注分段、时间带 | 横向探查、定位时刻 | 普通柱图丢失连续时间语义 |
| 趋势如何变化 | 折线图、范围折线图 | 范围切换、局部详情 | 平滑曲线制造不存在的峰谷 |
| 哪些值超过目标 | 柱状图 + 目标线、子弹图 | 调整阈值、即时高亮 | 可拖目标线没有业务意义 |
| 整体由哪些部分组成 | 分段占比条、100% 堆叠条 | 选段查看详情 | 类别很多仍用饼图/环图 |
| 少量类别占比 | 环形占比图 | 选中扇区、中心详情 | 比较相近比例或展示负数 |
| 类别规模和聚类关系 | 气泡图 | 选择、筛选、聚焦 | 需要精确排名仍用面积比较 |

## 选择步骤

1. 写出一句用户问题，例如“本周哪一天离 60 分钟目标最远”。
2. 判断核心关系：进度、时间、比较、趋势、阈值、构成或分布。
3. 确认需要精确读取还是模式发现。精确比较优先位置和长度；概览才考虑面积、角度和颜色。
4. 估计目标设备同时可见的数据量。超出可读范围时优先筛选、分页、滚动或聚合，不先缩小字号。
5. 只有当交互能揭示详情、改变范围或支持决策时才加入交互。

## 快速排除

- 类别超过约 5 个且比例接近：优先排序条形图，不用环形图。
- 需要精确比较气泡大小：改用条形图或点图。
- 只有一个数且没有阈值语义：用数字指标卡，不用仪表盘。
- 时间间隔不连续：不要用连续折线暗示中间值；使用点图或明确断点。
- 目标不可由用户调整：目标线只读，不提供拖动手势。
- 手机端类别标签拥挤：优先横向条形图、滚动或范围切换。

## 数据前置检查

- 单位和量纲是否一致。
- 百分比的分母是否明确，总和是否应为 100%。
- 时间是否涉及时区、自然日、周起始日和夏令时。
- 是否存在负值、零值、缺失值、异常值或超过 100% 的业务情况。
- 聚合方式是求和、平均、最大值还是去重计数。
- 实时数据应动画追赶，还是立即反映最新状态。
