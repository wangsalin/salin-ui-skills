# 6 种高级 Dashboard 导航交互模式

蒸馏自 @叨叨AI《第13集 | 6种高级Dashboard菜单》（2026-10-04）。视频原话："后台里点得最多的地方，菜单顺了整页就顺。"数值是视觉起点；AI 描述词多为视频原话，可直接用。

## 快速选型

| 模式 | 最适合 | 核心收益 |
|---|---|---|
| 滑动高亮块 Sliding Highlight | 各类后台侧边栏，想替换"左边一列字" | 视线跟随高亮块，切换有迹可循 |
| 就地展开子菜单 Inline Submenu | 一二级层级多、需收纳大量子页面 | 手风琴一次只开一组，不乱 |
| 顶部横排+下落面板 Top Mega Panel | 内容区需大宽度（宽表/日历/看板） | 把左侧宽度还给内容 |
| 底部停靠栏 Floating Dock | 功能入口少而精、极简高级感 | macOS 式质感，沉底不抢戏 |
| 命令面板 Command Palette | 页面多层级深、键盘重度用户 | ⌘K 直达，比点导航快 |
| 状态点与计数徽标 Status Badges | 工单/消息/审批类需提示未读 | 数字滚动+呼吸点，不错过更新 |

## 1. 滑动高亮块（Sliding Highlight）

**视频基线**：浅色侧边栏；当前选中项背后垫一块橙色/琥珀色圆角矩形高亮底块（胶囊形）；高亮块宽高跟随目标菜单项文字长短自动伸缩。

- 点击切换时高亮块从旧位置平滑滑动到新位置（250ms ease-out），落位带轻微回弹（spring damping ≈ 0.8），不是硬切。
- 高亮块只属于当前项；hover 用更浅的底色区分，不抢高亮块的戏。
- 当前项同时用字重/图标颜色强化，不只靠底块。

**AI 描述词**："菜单当前项用一块圆角高亮底，切换时高亮块从旧位置滑到新位置，宽高跟随目标项变化，带一点回弹"（视频原话）

## 2. 就地展开子菜单（Inline Submenu）

**视频基线**：深色侧边栏；可展开父级被橙色胶囊底块高亮，右侧 chevron；子项缩进排在父级下方，左侧一条细竖线把子项串连起来。

- 点击父级子菜单就地展开/折叠（250ms ease-in-out），箭头旋转 90°；子项依次错开淡入落下（stagger 40ms）。
- 手风琴行为：同一时间只展开一组，点开新组时上一组自动收回。
- hover 不能是唯一入口；触屏点击、键盘展开都要有等价操作。

**AI 描述词**："侧边菜单的一二级就地折叠展开，箭头旋转九十度，子项依次错开淡入，左侧用一条细竖线连接，同一时间只展开一组"（视频原话）

## 3. 顶部横排+下落面板（Top Mega Panel）

**视频基线**：取消左侧边栏，一级菜单横排于顶部导航栏，当前项用深色胶囊底块高亮；悬停/点击后从顶部下落一块大型白色 mega 面板，子页面分多列展示，每项带小图标+一行小字说明。

- 在菜单项之间横向移动时面板保持打开不收起、只切换里面内容（200ms 内容淡入）。
- 视频原话："左边的宽度全部还给内容"——适合宽表格、日历、数据看板类后台。
- 触屏用点击代替悬停；面板打开时 Esc 可关闭。

**AI 描述词**："导航改为顶部横排，悬停时下落一块通栏面板，子页面分列展示，带图标和一行说明，在菜单项之间移动时面板保持打开只切换内容"（视频原话）

## 4. 底部停靠栏（Floating Dock）

**视频基线**：黑色胶囊形（大圆角药丸）浮动栏，底部居中悬浮，只放白色线性图标（演示 5 个），无文字。

- macOS 式放大：鼠标指到的图标放大，相邻图标按距离跟随放大一点（150ms ease-out）；悬停时图标上方弹出小 tooltip。
- 每个图标需要可访问名称；触屏点按直接选中，不依赖悬停放大。
- 入口保持少而精（约 3–7 个），多了就换别的模式。

**AI 描述词**："菜单做成底部居中的浮动停靠栏，只放图标，悬停时当前图标放大、相邻图标跟随（放大）"（视频原话）

## 5. 命令面板（Command Palette）

**视频基线**：⌘K 在屏幕中央弹出浮动面板；顶部搜索输入框，下方命令/页面列表（每项带小图标）；打开时后面页面压暗并虚化（dim + blur）。

- 输入时实时过滤菜单项，命中文字高亮；支持上下键选择、回车直接跳转。
- Esc 关闭；无结果时显示空态，不许空白面板。
- 打开/关闭 200ms ease-out；背景虚化要有实色回退。

**AI 描述词**："加一个命令面板，按快捷键在屏幕中央弹出，背景压暗模糊，输入时实时过滤菜单项并高亮匹配文字，支持上下键选择和回车跳转"（视频原话）

## 6. 状态点与计数徽标（Status Badges）

**视频基线**：每个菜单项文字右侧带一颗橙色小圆点或橙色胶囊形数字徽标。

- 徽标数字变化时做滚动动效：旧数字向上滚走、新数字滚入（300ms ease-out，tabular-nums 等宽）；有更新的项状态点做呼吸动画（opacity 脉冲，约 2s 循环）。
- 数字超过 99 显示 99+；徽标是增强提示，不能是唯一的信息渠道（色盲/ reduced-motion 下仍需文字说明）。
- 尊重 prefers-reduced-motion：呼吸动画降级为静态点。

**AI 描述词**："菜单项右侧加状态点和计数徽标，有更新时数字滚动、状态点呼吸"（视频原话整理——原视频该条提示词后半句缺失）
