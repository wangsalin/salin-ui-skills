# Dashboard、侧栏与图表验收清单

按任务范围选择检查项。审查只报告已经通过代码、页面或可复现步骤确认的问题；实际实现必须尽量在真实页面验证。

## 1. 用户任务与页面架构

- [ ] 首屏能回答一个主要业务问题，而不是平均展示所有信息。
- [ ] 页面能说明发生了什么、可能原因和可执行的下一步。
- [ ] 概览、分析或运营主类型明确，密度符合任务。
- [ ] 全局筛选和局部筛选作用范围清晰。
- [ ] 指标、主洞察、次级证据和行动区没有重复表达。
- [ ] 关键操作不会被图表或装饰挤出可见区域。

## 2. 侧栏信息架构与视觉

- [ ] 入口按用户任务和频率排序，不按数据库模块名堆砌。
- [ ] 一级与二级层级可解释；双层导航各自职责明确。
- [ ] 业务分组简洁，没有权限过滤后的空组。
- [ ] 账户、工作区切换、帮助和退出位置稳定。
- [ ] 侧栏与内容区有主次，不和主图争抢注意力。
- [ ] active 不只依赖颜色；默认、hover、focus 和 disabled 可区分。
- [ ] 图标体系一致，长标签、翻译和徽标不溢出。
- [ ] 深色或玻璃模式在真实背景与主题下仍可读。

## 3. 图表业务与数据

- [ ] 每张图回答约定的用户问题。
- [ ] 单位、范围、聚合、时区、排序和百分比分母正确。
- [ ] 零值、负值、缺失、异常和超目标值真实呈现。
- [ ] 轴范围、截断、面积、角度和颜色不会夸大差异。
- [ ] 图表与指标、筛选、表格使用同一数据口径。
- [ ] 需要精确比较时没有误用气泡、环图或仪表盘。

## 4. 交互与联动

- [ ] 当前路由刷新后 active 正确。
- [ ] 整个导航链接点击区足够大，折叠与子菜单行为可预测。
- [ ] hover、点击、触摸、拖动和键盘有等价反馈。
- [ ] 选中项、Tooltip、图例、指标和表格详情同步。
- [ ] 全局筛选改变后所有受影响模块同步更新。
- [ ] 图表下钻、清除选择、返回和 URL 状态规则明确。
- [ ] 快速连续操作不会产生旧数据闪回、动画堆积或状态竞争。
- [ ] 拖动有边界、步长、取消与保存/回滚说明。

## 5. 状态完整性

- [ ] loading 不用旧数据冒充新结果，页面骨架保持稳定。
- [ ] empty 区分首次无数据、筛选无结果和接口未返回。
- [ ] error 说明影响范围并提供可执行重试。
- [ ] disabled 和无权限有一致策略，不静默失效或泄露入口。
- [ ] 陈旧数据标注更新时间和刷新状态。
- [ ] 数据范围切换后旧选择保留或清除有明确规则。
- [ ] 长菜单只滚动中间导航，底部账户区仍可达。

## 6. 响应式与布局

- [ ] 宽桌面、中等宽度和移动端都有明确重排规则。
- [ ] 移动端侧栏改抽屉或平台导航，不挤压主内容。
- [ ] 抽屉可关闭，关闭后焦点返回触发器，路由切换行为正确。
- [ ] 最小宽度下标题、图例、Tooltip、坐标轴和表格不意外溢出。
- [ ] 主内容没有双滚动条或错误偏移。
- [ ] 侧栏展开/收起后图表 resize、表格和 sticky 元素正确布局。
- [ ] 200% 缩放、低视口高度、横屏和安全区下关键入口可达。

## 7. 可访问性

- [ ] 使用真实 `nav`、链接、按钮、表格与表单控件。
- [ ] 当前页面设置 `aria-current="page"`；展开控件设置 `aria-expanded` 和 `aria-controls`。
- [ ] 收起图标有可访问名称和 tooltip，隐藏标签不重复朗读。
- [ ] 键盘焦点顺序符合视觉顺序，focus-visible 清晰且不被裁切。
- [ ] 颜色不是唯一信息通道；对比和色弱场景可读。
- [ ] 屏幕阅读器能获得图表摘要、当前选择和关键变化。
- [ ] 减少动画开启后仍能完成所有任务。

## 8. 性能与稳定性

- [ ] 业务上限数据量、菜单量和表格量下仍可操作。
- [ ] 容器缩放、字体加载、页面切换和隐藏后显示不会造成尺寸为 0 或错位。
- [ ] 组件卸载后没有遗留监听器、动画或定时器。
- [ ] 实时更新不会无限重绘、动画追赶或积累内存。
- [ ] 局部请求失败不会无原因拖垮整个页面。

## 9. 工程验证记录

最终汇报区分：

- 已运行且通过的格式化、Lint、类型检查、测试与构建。
- 已手动验证的真实业务路径和目标视口。
- 未运行的检查及原因。
- 尚存风险与建议下一步。

## 常见失败与修正

| 失败 | 根因 | 修正 |
|---|---|---|
| 页面像模板 | 先画等宽卡片，再寻找数据填充 | 从一个主要判断和行动路径重排层级 |
| 侧栏收起后难用 | 图标语义弱，hover 是唯一入口 | 加可访问名称、tooltip、点击固定和触摸替代 |
| 底部头像消失 | 整个侧栏一起滚动 | 三段 flex，中间 nav 独立滚动 |
| 内容左右跳 | hover 展开改变 AppShell 宽度 | 改覆盖式展开，固定时才改变布局 |
| 图表很多却无结论 | 每张图同权重、没有问题顺序 | 指定主洞察，其余改为证据或明细 |
| 图表误导 | 选型服从视觉而非比较任务 | 改用位置/长度编码并明确轴与口径 |
| 筛选结果不一致 | 各组件各自保存条件 | 建立单一状态来源和统一查询参数 |
| 毛玻璃显脏 | 背景无层次或对比不足 | 使用实色回退，必要时换普通表面 |
