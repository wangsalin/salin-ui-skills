# 布局模式库（桌面端网页）

## 1. 三栏式创作工作区
- 做法：左栏 = 步骤导航 + 历史记录（宽 240px，图标 + 文字）；中间 = 内容画布（最大、最亮，承载主要操作）；右栏 = 参数面板（宽 300px，可折叠：菜品、语气、字数、平台等）。渐进式披露：高级参数默认折叠。
- 适用：AI 生成向导、编辑器、配置页。
- 反模式：单栏长表单一撸到底；三栏等宽、画布被挤小。

## 2. Hero KPI 主卡
- 做法：工作台首页顶部一张大卡 = 大数字（32~40px，tabular-nums）+ 一句话说明 + 进度条/环形 + 一个主按钮。一屏有且只有一个视觉主角。
- 适用：工作台首页、数据首页。
- 反模式：顶部 4 张平权小卡；Hero 只有装饰图没有数字和动作。

## 3. KPI 小卡（三件套）
- 做法：灰色小标题 → 大数字 → 绿↑/红↓百分比胶囊 → 右上角迷你 sparkline。每张卡只回答一个业务问题。数字必须配对比和趋势。
- 适用：数据看板、首页第二屏。
- 反模式：裸数字；一张卡塞多个指标。

## 4. 数据表规范
- 做法：表头 12px 灰色弱化；行高 ≥ 48px；hover 高亮行，禁用斑马纹；状态列用小胶囊（色点 + 文字）；操作列用图标按钮 + tooltip，不用文字按钮堆砌；分页 + "已显示 x / 共 y 条"。
- 适用：任务中心、账单明细、产品库。
- 反模式：整行色块表示状态；操作列 4 个文字按钮并排。

## 5. 状态胶囊
- 做法：12px 文字 + 6px 色点：进行中琥珀、已完成绿、失败红、待处理灰。红色只给真实异常。
- 适用：所有列表的状态列。
- 反模式：大色块、大图标表示状态。

## 6. 步骤向导（顶部步骤条）
- 做法：顶部步骤条 "01 选场景 → 02 配素材 → 03 确认 → 04 结果"，当前步高亮、可回跳；每步一屏只做一件事；确认页汇总全部选择 + 点数抵扣明细；提交按钮注明消耗。
- 适用：多步创作流程（参考：短视频 4 步、海报 3 步、广告片 5 步）。
- 反模式：步骤藏在角落；确认页没有点数汇总。

## 7. 空 / 加载 / 错误三件套
- 做法：空状态放建议卡（3~4 张，点一下直接用）；加载用骨架屏，禁用"0 点/0 份"零值误导；错误给原因 + 重试按钮。
- 适用：所有异步页面。
- 反模式：白屏 + "暂无数据"；加载失败显示 0。

## 8. 知识库式资产页
- 做法：顶部统计条（14 产品 / 14 文件）→ 类型卡（文件/产品/门店/人物）→ 资产卡片带"可用度评分"（如 AI 可用度 85 分）+ 缺项待办 + 一键补齐。资产的核心是"AI 能不能用"，不是"存了多少"。
- 适用：知识库、素材库、模板库。
- 反模式：纯文件列表，没有可用度概念。

## 9. 深色结果预览（仪式感）
- 做法：工作区浅色，只有结果页用深色沉浸式展示（暖黑 + 暖金）。深色 = 出片时刻，不是默认皮肤。
- 适用：生成结果页、海报预览。
- 反模式：全站深色；深色页用纯黑 + 霓虹。
