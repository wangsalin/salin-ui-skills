# 设计 Tokens（桌面端网页）

## 配色方案

### 方案 A「暖纸青墨」（默认）
| 用途 | 色值 |
|---|---|
| 页面背景 | #F5F3EE |
| 卡片表面 | #FFFFFF |
| 边框 | #E5E1D8 |
| 主色（导航/标题/主按钮） | #2E5B4F（墨青绿，低饱和） |
| 强调色（仅 CTA / 关键数字） | #C96F2B（陶土橙） |
| 正文 / 次要文字 | #1F2937 / #6B7280 |
| 成功 / 警告 / 错误 | #2F9E63 / #D97706 / #DC2626 |

### 方案 B「石墨暖灰」（高密度信息页：任务中心、账单、数据看板）
| 用途 | 色值 |
|---|---|
| 页面背景 | #F8F8F6 |
| 卡片表面 | #FFFFFF |
| 边框 | #E4E4E2 |
| 主色（文字/图标，界面 95% 只用它） | #1B1B1B |
| 强调色（唯一彩色，只给可点的东西） | #047857 |
| 次要文字 | #737373 |

### 方案 C「深夜食堂」（仅结果预览深色）
| 用途 | 色值 |
|---|---|
| 背景 | #141210（暖黑） |
| 表面 | #1E1B17 |
| 文字 | #EDE8DF |
| 强调色 | #E8A33D（暖金） |

## 字阶（桌面端）
| 用途 | 字号 / 字重 |
|---|---|
| 表头、辅助信息、时间戳 | 12px / 500（表头）· 400（辅助） |
| 正文、表格、表单 | 14px / 400 |
| 按钮、导航 | 14px / 500 |
| 卡片标题、区块标题 | 16px / 600 |
| 页面标题 | 20~24px / 700 |
| Hero 大数字（只在主 KPI 卡） | 32~40px / 700 |

- 中文字体栈：`PingFang SC, HarmonyOS Sans SC, "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 数字：`tabular-nums` + `SF Mono, Roboto Mono, monospace`
- 中文慎用 900 字重

## 间距 / 圆角 / 阴影
- 8pt 网格：所有间距为 8 的倍数（8/16/24/32/48/64）
- 圆角：卡片 12px；按钮 8px 或 pill；输入框 8px；小标签 6px
- 阴影：最多 1 层淡阴影；弹窗可用 1 层稍强阴影 + 遮罩 rgba(0,0,0,0.32)
- 布局：内容区 1200~1440px 居中；栅格 12 列，gutter 24px
