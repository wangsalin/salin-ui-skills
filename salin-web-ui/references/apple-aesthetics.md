# Apple 美学规则（桌面端网页）

来源：西瓜同学🍉《UI高级审美设计｜Skill实战》第 20 集「UI设计Skill: 让AI学会Apple设计美学」（2026-10-22）。蒸馏日期 2026-10-23。

## 蒸馏三步法（本集方法论）

1. **读设计**：从参考作品拆四个维度——布局、留白、材质、交互。
2. **整理成 Skill**：把"感觉对"变成可复用的判断规则（就是下面这份文件）。
3. **换提示词**：同一套规则，配三种表达（见 §10），喂给 Codex / WorkBuddy 等 AI 编程工具。

## 1. 图片主角 + Bento 布局
- 做法：以摄影图片为视觉中心；Bento 网格承载图片卡片（大卡片放主视觉、小卡片放辅助内容）；点击分类时卡片平滑退出并自动重排（FLIP 动画思路：先记录位置 → 改变布局 → 反转位移补间）。
- 适用：灵感库、作品集、内容型产品首页。
- 反模式：文字为主、图片当装饰小图；分类切换整页闪烁重载。

## 2. 大面积留白
- 做法：区块间距从 py-32 起步；一屏只讲一件事；正文行距放宽到 1.8。
- 适用：品牌站、产品 landing 页。
- 反模式：为了"充实"把页面塞满；留白只加在页面底部。

## 3. 柔和圆角
- 做法：图片卡片 16~24px 大圆角；圆角与容器统一（图片圆角 = 卡片圆角 - 内边距）；按钮 pill。
- 适用：消费级产品、创意类站点。
- 反模式：直角图片卡 + pill 按钮混用；同一页面三种圆角。

## 4. 深浅模式同步切换
- 做法：设计之初就定义两套 token；切换时整套视觉同步过渡——颜色、图片亮度、阴影、边框一起变，不是只换背景色。
- 适用：所有消费级网页。
- 反模式：深色模式只有反色背景，图片刺眼、阴影丢失、文字对比度崩。

## 5. 玻璃材质（克制使用）
- 做法：backdrop-blur + 1px 半透边框 + 顶部 1px 高光；只用在浮层、导航栏、悬浮卡片。
- 适用：Apple 风、媒体类、创意工作室站点。
- 反模式：全页玻璃拟态；毛玻璃下文字对比度不足。

## 6. 交互规则句式
- 做法：把联动写进同一句——"当发生时，让产生"。为联动命名、为响应命名。例：当点击分类时，让非目标卡片淡出收缩、目标卡片补位重排。
- 适用：所有带状态联动的页面（筛选、切换、展开）。
- 反模式：交互逻辑散落在各处，没有统一规则描述；联动靠"顺手写"。

## 7. 内容"一组交接"
- 做法：主图与说明文案绑定为一组，切换时同步过渡（一起淡出、一起进入）；不允许图先变、文案后变的节奏错位。
- 适用：案例展示、作品详情、轮播区。
- 反模式：图片和文案各自独立切换。

## 8. 编辑式排版（Editorial）
- 做法：超大标题（clamp 3~5rem）+ 不对称网格 + 摄影图穿插；标题可跨列、图片可破格，打破 12 列等宽。
- 适用：个人主页、工作室站点、品牌故事页。
- 反模式：全站 12 列等宽网格 + 居中标题 + 三段式。

## 9. 字母级悬停响应
- 做法：鼠标经过互动文字时，每个字母依次响应（stagger 延迟 30~50ms），不是整词一起变。
- 适用：导航、标题、CTA 文字。
- 反模式：整词 hover 只变色。

## 10. 提示词模板（三种表达）

同一套规则，三种说法，按场景选用：

**简洁版**（快速出图/初稿）：
> Apple 极简风，图片当主角，Bento 布局，大面积留白，柔和大圆角。

**详细版**（VibeCoding 直接用，本集案例一原话改写）：
> 结合 UI 设计 Skill，采用 Apple 风格的极简布局，以图片为视觉中心，使用 Bento 风格，大面积留白和柔和圆角，加入分类筛选、卡片平滑重排、图片展开及深浅模式切换，保持统一的视觉风格与交互反馈。

**技术版**（给 AI 编程工具的 token 级描述）：
> 12-col grid → Bento cells (2fr/1fr mix), radius 20px, section spacing py-32, light/dark token pairs with transition, FLIP reflow on filter, staggered letter hover (40ms), backdrop-blur nav only.
